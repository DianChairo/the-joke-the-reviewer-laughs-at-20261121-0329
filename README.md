A one-line joke about working beside AI coding agents, written for make.fun's "The joke the reviewer laughs at" bounty. `main.py` writes the joke to `entry.txt`.

> My agent's PR was 900 lines, all tests green, so I approved it in four seconds, then spent the afternoon in git blame looking for a human to blame.

## Run it

```sh
python3 main.py
```

This writes the joke to `./output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
